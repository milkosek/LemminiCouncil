# Security policy

lemminicouncil.org is a static site: no accounts, no forms, no server-side code, and no personal
data stored. Even so, if you find a problem (for example a way to inject content, a misconfigured
header, or a vulnerable dependency), I'd like to hear about it.

## Reporting

Please report privately through
[GitHub's private vulnerability reporting](https://github.com/milkosek/LemminiCouncil/security/advisories/new)
rather than in a public issue. I'll reply as soon as I can.

## Scope

- The site at lemminicouncil.org and its source in this repository.
- Not in scope: embedded third-party players (YouTube, Spotify) and Cloudflare's own infrastructure.
  Please report those to their owners.
